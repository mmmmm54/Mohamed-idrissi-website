# Adding case-study artwork

Each project lives in `public/projects/<slug>/`.
Slugs: `mat`, `exploremorocco`, `justfit`, `maalem`, `aqluma`, `vanysis`.

Place numbered images in these optional folders:

- `identity/01.jpg`: logos, typography, brand guidelines and identity applications.
- `social/01.jpg`: social posts and stories, displayed without cropping.
- `campaigns/01.jpg`: posters, campaigns, packaging and other applications.

Use `01`, `02`, `03` etc. JPEG, PNG and WebP are supported. Each populated folder automatically creates its section; empty folders are not displayed. Existing numbered images directly inside the project folder continue to work as a general gallery. Original aspect ratios are preserved.

Restart the local server or rebuild after adding files. No content claims or outcome figures are generated from uploaded images. Confirm the existing draft narrative separately before publication.
