# D5 shot setup (per shot)

1. Load the camera, set 1080 × 1920.
2. Place hero vegetation in the foreground first (palms, pink trees), then mid-ground, then background.
3. Add 2-6 people per lifestyle shot (SH03, SH05, SH06, SH08, SH10). No people in SH02 / SH09.
4. Cars only in SH01, SH02, SH04 (parking).
5. Render a still for approval → this becomes the Higgsfield hero frame (`output/higgsfield/03_HERO_FRAMES/`), or render the D5 camera move directly.
