# Asset sources — Mirleft Bay

Nothing in this project comes from an unclear source.

## Used

| What | Source | Licence |
|---|---|---|
| All building, terrain and site geometry | Generated by the scripts in `blender/` from the client's plan F01, catalogue F02, photos and Google Earth view | Project-owned |
| All materials | Procedural Blender node trees (`blender/07_build_materials.py`) | Project-owned |
| Foliage textures (olive cards, hedge leaves, palm fan) | Generated with Python/PIL in this project (`assets/textures/generated/`) | Project-owned |
| Palms, olives, scrub, grass | Procedural meshes (`blender/09_build_landscape.py`) | Project-owned |
| Sky | Blender's built-in Nishita sky model | Blender (GPL). Rendered images are unrestricted. |

## Wanted but BLOCKED

| What | Why it is needed | Where | Format / resolution | Free source |
|---|---|---|---|---|
| Lime render / plaster scan | Authentic trowel texture for close-ups (SH05, SH09) | All façades | PBR set (Color, Roughness, Normal, Displacement), 4K | Poly Haven *plaster* textures, ambientCG *Plaster* (CC0) |
| Warm rubble stone wall | Retaining walls, garden walls | Site edges, lots | PBR 2K-4K | Poly Haven *stone_wall* family (CC0) |
| Weathered wood planks | Pergolas, lattice | Duplex / villas | PBR 2K | Poly Haven *wood planks* (CC0) |
| Concrete pavers | Roads, sidewalks | Whole site | PBR 2K | ambientCG *PavingStones* (CC0) |
| Golden-hour HDRI | Richer sky and reflections | World | EXR 4K-8K | Poly Haven HDRIs, filter `time_of_day=sunset`, outdoor (CC0) |
| Palm tree models | Hero vegetation | Gardens, streets | glTF / .blend | Poly Haven has few palms. Otherwise a licensed model supplied by the client. |

**Blocker:** this cloud environment's network policy refuses `api.polyhaven.com`, `dl.polyhaven.org` and `ambientcg.com` (HTTP 403 on CONNECT, tested twice on 2026-10-01). To unblock it, add these hosts under the environment's Network access settings. The pipeline then swaps the procedural materials for the scans without changing any geometry.
