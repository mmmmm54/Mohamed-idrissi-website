# Mirleft Bay — architectural visualisation pipeline

The source documents define reality, Blender builds it, and Higgsfield adds motion.

| Folder | Contents |
|---|---|
| `input/` | Client sources: plan de masse (PDF, kept local), catalogue (PDF, kept local), photos, Google Earth views |
| `specs/` | Inventory, Project Bible, missing information, answered questions, asset requirements, production status, reference crops |
| `blender/` | Modular pipeline scripts (`20_pipeline.py` runs everything) + digitised site data |
| `assets/` | Generated textures, asset / texture manifests, sources and licences |
| `output/previews/` | Current 9:16 renders |
| `output/validation/` | Validation report, top view over the plan, registration checks |
| `output/higgsfield/` | Location / style bibles, shot list, hero frames, motion prompts, negatives, continuity, edit structure |
| `output/blender/` | Render, lighting and camera guide (MODE B) |
| `output/checkpoints/` | .blend checkpoints (not in git: rebuild with the pipeline) |

Scope (client, 2026-10-01): the whole 8.2 ha site with all buildings as detailed instances, plus the hero Tranche 1 duplex. Programme names come from the 2026 catalogue and positions from the 2016 permit plan. Delivery is vertical 9:16 with golden hour as the master look.
